These are hosted on port 8501 locally, which is the default port for Streamlit apps.
To run them, download the .py file, open in vs code and write the command in the terminal "streamlit run code.py"
For checkbox to do app, I have used Supabase for storing data entered, secrets: url and key are supposed to be embedded in the .env file. A part of practice for making a scheduler cron job.
